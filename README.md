# Общие модули Odoo

Модули, нужные во всех направлениях сразу. Версия в манифесте — `1.x.y`, без
серии: модуль должен ставиться и на 19, и на 20.

| Модуль | Назначение |
|---|---|
| `otk_bridge` | Выполняет загрузку данных и откатывает транзакцию, чтобы `otk load` имел сухой прогон. Внешний API Odoo откатывать не умеет. |

**Тонкость переносимости:** файл прав назван и устроен по-разному в 19 и 20
(`ir.model.access.csv` на модели `ir.model.access` против `ir.access.csv` на
`ir.access`). Поэтому здесь держим только модули, достаточно тонкие, чтобы
обойтись без файла прав вовсе.
